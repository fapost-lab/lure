# Research — Lure

Collected on 2026-11-15. Vendor and affiliate pages are marked (3p); figures change often.

## Who already does this

- Audits and drafting are well covered: the claude-seo plugin for Claude Code (~29.6k stars:
  technical, schema, GEO audits; `/seo drift` snapshots; no outcome tracking, no publishing) —
  https://github.com/AgriciDaniel/claude-seo ; OpenClaw marketing skills (37 skills, Search
  Console and ads connectors) — https://clawhub.ai/LeoYeAI/openclaw-marketing-skills ;
  commercial agents SEObot, SEO.ai, Search Atlas OTTO, Surfer (3p) —
  https://nightwatch.io/blog/best-ai-seo-agents/
- Nobody closes the loop "change → measure weeks later → lesson". SEO split testing
  (SearchPilot) needs about 1,000 organic visits a day per tested section —
  https://www.searchpilot.com/resources/blog/what-is-seo-split-testing ; before/after tools
  admit seasonality and updates skew results — https://support.seotesting.com/en/category/seo-tests-1acjzdy/

## AI-search visibility

- Measured by sampling a fixed prompt set; fewer than 1 in 100 repeated runs return the same
  brand list (SparkToro/Gumshoe, 2026) —
  https://www.searchenginejournal.com/ai-recommendations-change-with-nearly-every-query-sparktoro/566242
- AI referrals are a small share of traffic (~0.3%), but AI Overviews cut the top result's CTR
  sharply (3p) — https://seranking.com/blog/ai-traffic-research-study/

## Google on AI content

- Scaled content abuse targets pages made to manipulate rankings "no matter how it's created" —
  https://developers.google.com/search/docs/essentials/spam-policies
- All AI-generated content, metadata included, should be fact-checked by a person —
  https://developers.google.com/search/docs/fundamentals/using-gen-ai-content

## Platforms

- LinkedIn: personal posting via `w_member_social`; the User Agreement bans unauthorised
  automation; company pages need a vetted organisation —
  https://www.linkedin.com/help/linkedin/answer/a1341387 ,
  https://learn.microsoft.com/en-us/linkedin/marketing/community-management-app-review
- X: pay per use, free tier closed (3p) — https://docs.x.com/developer-guidelines
- Reddit: every new OAuth token needs approval (3p) — https://www.redditapis.com/blogs/reddit-data-api-2026
- Habr bans texts generated by neural networks — https://habr.com/ru/docs/help/rules/ ;
  Hacker News bans AI-generated comments — https://news.ycombinator.com/newsguidelines.html ;
  dev.to forbids AI-assisted articles that promote a business —
  https://dev.to/guidelines-for-ai-assisted-articles-on-dev
- Telegram: a bot that is a channel admin posts freely — https://core.telegram.org/bots/faq

## Data access

- Search Console and GA4 APIs need a Google Cloud project, or a shipped OAuth client; an
  unverified client warns users and is capped at 100 users —
  https://support.google.com/cloud/answer/15549945 ,
  https://developers.google.com/analytics/devguides/reporting/data/v1/quotas
- Search Console limits — https://developers.google.com/webmaster-tools/limits
- Bing Webmaster connects by API key — https://learn.microsoft.com/en-ca/bingwebmaster/getting-access
